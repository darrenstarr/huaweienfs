# NAME

esunrpc_rpc_create - allocate and connect a new esunrpc RPC client

# SYNOPSIS

**#include <esunrpc/clnt.h>**

**struct esunrpc_rpc_clnt \*esunrpc_rpc_create(struct esunrpc_rpc_create_args \***\ *args*\ **);**

# DESCRIPTION

**esunrpc_rpc_create**() allocates a new RPC client object, builds
its transport, runs the connect handshake synchronously, and
returns a usable client. This is the only constructor for
**struct esunrpc_rpc_clnt** — there is no "construct empty, fill
in later" path; all required fields are passed in *args*.

The fields of *args* the caller must set are:

**.net**
:   network namespace (typically **&init_net**).

**.protocol**
:   transport protocol — **IPPROTO_TCP** or **IPPROTO_UDP**.

**.address** and **.addrsize**
:   server endpoint as a **struct sockaddr** and its size.

**.servername**
:   printable string used in diagnostics. Need not be unique.

**.program**
:   pointer to the **struct rpc_program** describing the RPC
    program. For the bundled rpcbind program use
    **&esunrpc_rpcb_program**.

**.version**
:   protocol minor version.

**.authflavor**
:   one of **RPC_AUTH_NULL**, **RPC_AUTH_UNIX**, etc.

The returned client comes with one reference owned by the caller.
Drop it via **esunrpc_rpc_shutdown_client**(3) (synchronous
teardown) or **esunrpc_rpc_release_client**(3) (asynchronous
ref-drop).

# RETURN VALUE

On success, returns a non-error pointer. On failure, returns an
**ERR_PTR**() — use **IS_ERR**() and **PTR_ERR**() to inspect.

Common errnos:

**-EINVAL**
:   *args* invalid (missing required field, unknown family).

**-ECONNREFUSED**
:   the server actively refused the connection.

**-EHOSTUNREACH**
:   no route to *args->address*.

**-ENOMEM**
:   allocation failed (rare).

# CONTEXT

Sleeps. Must be called from process context. The caller need not
hold any lock; the function takes whatever it needs internally.

# THREAD SAFETY

Reentrant. Multiple cores may call concurrently with different
*args* — each call produces an independent client. Two clients
talking to the same server have independent transports.

# EXAMPLE

```c
struct sockaddr_in srv = {
    .sin_family = AF_INET,
    .sin_port   = htons(111),
    .sin_addr   = { .s_addr = htonl(INADDR_LOOPBACK) },
};
struct esunrpc_rpc_create_args args = {
    .net        = &init_net,
    .protocol   = IPPROTO_TCP,
    .address    = (struct sockaddr *)&srv,
    .addrsize   = sizeof(srv),
    .servername = "rpcbind",
    .program    = &esunrpc_rpcb_program,
    .version    = 2,
    .authflavor = RPC_AUTH_NULL,
};
struct esunrpc_rpc_clnt *clnt = esunrpc_rpc_create(&args);
if (IS_ERR(clnt)) {
    pr_err("create failed: %ld\n", PTR_ERR(clnt));
    return PTR_ERR(clnt);
}
/* ... use clnt ... */
esunrpc_rpc_shutdown_client(clnt);
```
